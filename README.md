## 🧩 Learn by Playing (Gamified Coding Sites)

Sites where the "lesson" is a game you play — you write real code to win, solve, or progress. A great companion to the resources below, not a replacement for them.

| Resource | Description |
| --- | --- |
| CodeCombat | 🎮 Multiplayer strategy game — write real Python or JavaScript to guide your hero through dungeons and battles |
| CodinGame | 🎮 Puzzle- and battle-based coding challenges in 25+ languages, beginner to expert |
| Codewars | 🎮 Solve bite-sized "kata" challenges and rank up through martial-arts-style belts, in 15+ languages |
| CheckiO | 🎮 Solve Python or JavaScript puzzles to guide a character through a game world |
| Screeps | 🎮 A real always-running MMO strategy game where the gameplay itself is the JavaScript you write |

> More coding games (CSS, SQL, JS, Git…) are sprinkled into the relevant sections below, marked with 🎮.
